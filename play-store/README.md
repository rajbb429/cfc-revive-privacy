# Google Play store assets

| File | Where it goes in Play Console | Spec |
|---|---|---|
| `short-description.txt` | Main store listing → Short description | 79 / 80 characters |
| `full-description.txt` | Main store listing → Full description | 2,541 / 4,000 characters |
| `app-icon-512.png` | Main store listing → App icon | 512 × 512 PNG, full bleed (Play rounds the corners) |
| `feature-graphic-1024x500.png` | Main store listing → Feature graphic | 1024 × 500 PNG |
| `screenshots/*.png` | Main store listing → Phone screenshots | 1080 × 1920 (9:16), upload in number order |

Screenshots were taken from the real app at a 360 × 640 phone size (3× scale).
The unlock screen shows the Android app's purchase state, with no price, since the
price comes from Google Play.
